# 语音输入：Apple 本地与豆包二遍

鼠须管构建内置流式听写。默认使用 Apple 本地 `SpeechAnalyzer`/`SpeechTranscriber`；可在“语音设置…”切换豆包云识别（二遍，见 [doubao-speech](doubao-speech.md)）。两种模式共用词典、语音别名、中英文间距和手动编辑保护。

## 使用

选择鼠须管，在可编辑文本框中结束当前候选输入。默认右 Option：

| 操作 | 快捷键 |
|---|---|
| 开始/停止 | 轻按松开右 Option，或按住约 0.25 秒；再按一次结束 |
| 输入法内备用 | `Control + Shift + Space` |
| 取消本轮 | `Escape` |

听写时屏幕下方显示黑色浮条：左侧取消、中间波形、右侧完成。浮条不抢编辑器焦点。停止后等待最终结果；超过 12 秒保留已显示文字并结束。语音撤回已关闭；取消录音仍会回滚本轮未手动修改的文字。

首次按快捷键只请求麦克风权限，不开始录音；授权后回到文本框再按一次。拒绝后可在系统设置 → 隐私与安全性 → 麦克风重新允许。Apple 模式需要 macOS 26、支持 `SpeechTranscriber` 的设备和已安装 `zh_CN` 模型；不兼容时提示并停止，不会自动下载或切云。

## 权限

- 麦克风：录音和声音测试。
- 辅助功能：全局快捷键、结束时检查当前焦点、读取必要的短范围并安全写入。
- 辅助功能已授权时不再要求输入监控；输入监控仅作为旧授权的兼容备用路径，不保存按键内容。

设置页的“打开系统设置”会跳到对应页面。必要时重启输入法。签名身份变化可能导致系统重新要求授权；先确认授权条目指向 `/Library/Input Methods/Squirrel.app`。需要清除本应用专属旧授权时：

```sh
tccutil reset Accessibility im.rime.inputmethod.Squirrel
tccutil reset ListenEvent im.rime.inputmethod.Squirrel
```

这只撤销旧授权，不授予权限，也不影响其他应用。

## 输入设备

“语音设置…”可选择跟随系统默认或固定设备；固定设备只影响鼠须管，不改变系统默认输入。可在设置内测试音量；设备断开时提示不可用，不自动切换。设备 UID 和偏好存在 `im.rime.inputmethod.Squirrel.Voice`，每台电脑独立配置。

## 实时写入与手动编辑保护

- 开始时在原输入框边说边显示；只允许识别器修订当前语音尾部。
- 写入前核对宿主、光标、marked/selected range 和对应文字（UTF-16），不读取整份文档。
- 听写中打字、方向键或鼠标编辑会封印完整暂定文字，撤销该段的后续修订权限；新段落可继续。
- 五笔/拼音候选尚未结束时，不把语音写进候选区。
- 切换应用或原生输入上下文不可用时，录音继续，未写入文字进入同一黑色浮条的上方预览；焦点回到可编辑区域且原生 IMK 可用时，只补写已封印前缀之后的尾文，不重复已上屏文字。
- 结束时再检查焦点，只写入尚未交付的文字；不能可靠写入时保留可编辑结果，由用户点击复制。不会另开结果窗口。
- iTerm2 有单独的真实网格坐标/停顿提交保护；其他终端和网页宿主仍需各自实测。

## 豆包重写

豆包模式支持在录音中/历史记录上做二级轻整理、三级重整理：先结束听写，再用独立方舟 API Key 请求文本模型；结果只在同一黑色浮条上方预览、编辑、复制，不自动改宿主或历史。快捷键和配置见 [doubao-speech](doubao-speech.md)。

## 隐私

Apple 模式音频只在本机 helper 内存和本地模型处理，不上传。选择豆包意味着本次音频发送到固定火山引擎 WSS 接口并按所选资源计费；热词只发送用户勾选的固定输出词。麦克风测试不连接云服务。诊断只记录启动/停止、音频格式和音量，不含听写正文、音频样本或凭证。

## 验证

```sh
bash rime/tools/test_voice.sh
bash rime/tools/test_doubao_voice.sh
bash rime/tools/test_voice_hud.sh   # GUI
bash rime/tools/test_voice_rewrite.sh
```

桌面验收至少覆盖 TextEdit、iTerm2、浏览器/Codex：持续上屏、停顿续说、切应用、手动编辑 `[KEEP]`、结束写入、无输入框复制。模拟 NSTextView/协议通过不能替代真实宿主、麦克风和系统权限。

# 豆包二遍语音识别

“语音设置…”中可选择 **Apple 本地识别** 或 **豆包云识别（二遍）**。默认保留 Apple；只有用户选择豆包并配置凭证后才启用云识别。麦克风测试始终在本机完成。

二遍使用火山引擎双向流式接口：先返回暂定文字，再按分句做第二次识别，只有 `definite=true` 的最终段落才交给输入法。暂定修订、正式上屏和手动编辑保护共用同一套范围校验；二遍结果不得覆盖用户已修改的内容。

接口参考：[官方流式语音识别文档](https://docs.volcengine.com/docs/6561/1354869?lang=zh)、[双向流式 ASR](https://docs.volcengine.com/docs/DoubaoVoice/bidirectional-streaming-automatic-speech-recognition-websocket?lang=zh)。

## 配置

1. 打开“语音设置…” → “豆包云识别（二遍）”。
2. “配置豆包…”选择账号已开通的模型和计费版本。
3. 新版控制台填写语音 API Key；旧版控制台填 App ID + Access Token。
4. 保存后开始听写。

| 设置 | 对应资源 |
|---|---|
| 2.0 · 按时长（推荐） | `volc.seedasr.sauc.duration` |
| 2.0 · 按并发 | `volc.seedasr.sauc.concurrent` |
| 1.0 · 按时长（兼容） | `volc.bigasr.sauc.duration` |
| 1.0 · 按并发（兼容） | `volc.bigasr.sauc.concurrent` |

浏览器登录控制台不等于接口已鉴权；应用不会自动开通服务、购买资源或创建密钥。密钥/Token 存在登录钥匙串（service `im.rime.inputmethod.Squirrel.DoubaoSpeech`），不写入 YAML、偏好、仓库或日志。重新打开配置时不显示原值；留空保持旧值，“删除凭证”移除本应用凭证。

切换识别方式/模型对下一次听写生效；失败时保留已识别文字并显示错误，不静默切换其他云服务。

## 协议与行为

- 固定连接 `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async`。
- 16 kHz、单声道、16 位小端 PCM，每包约 200 ms。
- 启用 `enable_nonstream`、`show_utterances`，保留标点/数字规范化；不启用语义顺滑或未配置的文字模型。
- 分句最终结果、重复结果、迟到暂定结果按音频起点去重；已确认段落不重复插入。
- 结束发送最后一包并等待二遍结果；网络回压、断线或最终结果超时会停止会话，不无限缓存音频。
- 辅助功能只读当前输入框和语音持有的短范围；文档上下文、剪贴板、其他应用文字不发送。
- 录音只在内存/连接中处理，不生成真实录音文件；诊断不含密钥、音频或听写文字。

选择豆包即表示本次录音发往火山引擎并按所选资源计费；Apple 模式仍在本机识别。

## 热词与别名

- 语音别名是本机精确纠错规则：命中识别原文后替换为固定输出，不上传、不改变模型能力；Apple 模式也可用。
- 豆包热词是概率引导：词典里勾选“豆包热词”的词，下一次豆包录音通过 `request.corpus.context` 的 `hotwords` 发送固定输出。编码、权重、别名、未勾选词和文档上下文不发送。
- 每次录音连接只发送一次；最多 5000 个不同热词，过大请求本机拒绝。Apple 模式不发热词。热词表不自动创建或同步。
- 热词只是引导，格式原样输出仍由本机词典保护。二遍比流式一遍能利用更多热词，但服务端仍可能按 token 容量截断；精简勾选更可靠。

## 手动文字重写

“配置豆包…”支持独立的方舟文本 API Key 和模型 ID。录音中点击黑条右侧重写图标，或从听写历史选择记录，可做二级轻整理/三级重整理。请求前先结束听写；结果只在黑条上方预览、编辑、复制，不自动改宿主或历史。重写快捷键只在黑条获得焦点时生效。凭据同样只存 Keychain；没有配置时不发起请求。

## 已知限制

- 真实服务效果依赖账号资源、网络和模型；模拟回环通过不代表真实识别质量。
- 既有录音/识别路径没有语音撤回；取消录音只回滚本轮未手动修改的文字。
- 豆包引擎/服务升级可能改变错误码、热词或上传行为；不自动开通或购买。
- 证书/签名变化可能让旧 Keychain ACL 需要重新认证；在配置页重新保存并完成系统认证，不要把密钥发到聊天。

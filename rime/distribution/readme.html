安装鼠须管（Squirrel）

这是 Rime 输入法的 macOS 前端。安装包会写入 /Library/Input Methods，并保留已有的词库、设置和语音凭证。

首次安装

  1. 安装完成后，打开 系统设置 → 键盘 → 输入法，点击“+”添加“鼠须管”。
  2. 如果列表中没有“鼠须管”：请先 注销并重新登录，再添加。macOS 首次发现新的输入法时，输入源列表可能要到下次登录才刷新。
  3. 添加后从右上角输入法菜单选择“鼠须管”，即可使用五笔、拼音和语音听写。

语音听写

从输入法菜单打开“语音设置…”，按引导授予麦克风、辅助功能和输入监控权限；默认快捷键是单按右侧 Option（⌥），可在语音设置中修改。第一次真正开始语音时会请求麦克风权限。

符号与 GIF

中文模式下 `、#、%、* 直接上屏；输入 /fh 打开可搜索的符号大面板，输入 /gif 搜索在线 GIF。GIF 第一次使用前，从输入法菜单打开“GIF 搜索设置…”选择服务并保存 API Key。选中 GIF 只复制到剪贴板，回到输入框按 ⌘V 粘贴，不自动粘贴。

升级安装

词库、学习记录、设置和语音凭证会保留；通常不需要重新添加输入源。如果升级后输入源消失，注销并重新登录即可。

安装完成后，鼠须管第一次启动时也会显示一份简短的引导。

安装完成

首次安装：打开 系统设置 → 键盘 → 输入法，点击“+”添加“鼠须管”。如果列表中没有“鼠须管”，请先 注销并重新登录，再添加（macOS 首次安装需要刷新输入源列表）。

添加后从右上角输入法菜单选择“鼠须管”。语音听写：从输入法菜单打开“语音设置…”，按引导授予麦克风、辅助功能和输入监控权限；默认快捷键是单按右侧 Option（⌥），可在语音设置中修改。

符号与 GIF：中文模式下 `、#、%、* 直接上屏；/fh 打开符号大面板。使用 /gif 前，从输入法菜单打开“GIF 搜索设置…”选择服务和 API Key；选中后只复制，按 ⌘V 粘贴。

升级安装：词库、学习记录、设置和语音凭证会保留，通常不需要重新添加输入源；如果输入源消失，注销再登录即可。

鼠须管第一次启动时也会显示同样的引导。

# 豆包二遍语音识别

语音设置可以选择 **Apple 本地识别** 或 **豆包云识别（二遍）**。默认保留 Apple，云识别只有在用户选择豆包并配置凭证后才会启用。麦克风音量测试始终在本机完成，不连接云服务。

二遍使用火山引擎优化双向流式接口：先返回暂定文字，再对分句进行第二次识别，`definite=true` 才作为正式段落交给输入法。暂定修订、正式上屏和手动编辑保护共用同一套范围校验；二遍结果不能覆盖用户已经修改的内容。

接口依据：[大模型流式语音识别官方文档](https://docs.volcengine.com/docs/6561/1354869?lang=zh)，[用户提供的新版文档入口](https://docs.volcengine.com/docs/DoubaoVoice/bidirectional-streaming-automatic-speech-recognition-websocket?lang=zh)。

## 配置

1. 打开鼠须管的“语音设置…”，选择“豆包云识别（二遍）”。
2. 点击“配置豆包…”。选择账号已开通的识别模型与计费版本。
3. 新版控制台填写语音 **API Key**；旧版控制台选择 **App ID + Access Token**。
4. 保存，再开始听写。

浏览器登录控制台与接口鉴权是两件事。模型服务需要已经开通，配置的资源必须与账号授权一致。应用不自动开通服务、购买资源或创建密钥。

| 设置 | 对应资源 |
| --- | --- |
| 2.0 · 按时长（推荐） | `volc.seedasr.sauc.duration` |
| 2.0 · 按并发 | `volc.seedasr.sauc.concurrent` |
| 1.0 · 按时长（兼容） | `volc.bigasr.sauc.duration` |
| 1.0 · 按并发（兼容） | `volc.bigasr.sauc.concurrent` |

密钥和 Token 保存在本机登录钥匙串，不写入仓库、YAML 或偏好文件。重新打开配置后，密钥输入框不会显示原值；留空保持原凭证，“删除凭证”移除本应用的语音接口凭证。App ID、所选模型和识别方式属于普通偏好设置。钥匙串被锁定或更新签名后无法访问时，需要解锁或在配置页重新保存凭证。

切换识别方式与模型对下一次听写生效；当前会话不会悄悄切换服务。豆包失败时提示错误并保留已经识别的文字，不自动改用其他云服务。

## 数据与行为

- 连接固定为 `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async`。
- 发送 16 kHz、单声道、16 位小端 PCM，每包约 200 ms。
- 请求启用 `enable_nonstream`、`show_utterances`，保留标点与数字规范化；语义顺滑和智能文字整理未启用。
- 分句最终结果、重复结果和迟到暂定结果按音频起点去重，已经确认的段落不会重复插入。
- 结束录音发送最后一包，等待二遍结果；网络回压、断线和最终结果超时会停止会话。不会无上限缓存录音。
- 辅助功能只检查当前输入框及语音持有的短文字范围；文档上下文、剪贴板、其他应用文字不发送给豆包。
- 录音仅在内存与连接中处理，不生成真实录音文件。诊断不输出密钥、音频或听写文字，服务端错误只显示错误码，避免回显敏感内容。

选择豆包即意味着把本次录音发送到火山引擎，并按所选资源计费；Apple 模式继续在本机识别。模型选择和联网提示会在设置页显示。

## 编译与测试

完整构建、安装同[编译安装文档](build-squirrel.md)。构建需要 Xcode 26；豆包运行路径使用 macOS 13 已有的 API，不依赖本地 SpeechTranscriber 模型。Apple 路径仍需要 macOS 26 和本地中文模型。

```sh
bash rime/tools/test_doubao_voice.sh
bash rime/tools/test_voice.sh
```

豆包测试需要 Node.js，仅使用内置模块与本机回环网络：模拟握手、PCM 分包、暂定结果修订、二遍确认、重复最终结果、服务端错误、断线、回压及最终结果超时。它不会访问真实火山引擎账号，不读取麦克风，也不需要密钥。Apple 测试调用本机真实模型，验证输入范围、手动编辑保护和撤回。

### 停顿容忍与词典格式（VoiceInputVersion=6）

设置页增加 0.8、1.6、2.5、4 秒四档停顿容忍，默认 1.6 秒；通过启动配置传入助手，再发送 `request.end_window_size`。实时文字照常显示，延后静音段的最终确认。接口按静音切段，无法保证语义上属于同一句；未来整理需结合整轮上下文，保护手动编辑范围。参数和限制见[官方接口文档](https://docs.volcengine.com/docs/6561/1354869?lang=zh)。

中英文间距与固定词条在本机处理，五笔、拼音和语音共用词典。语音识别别名不会上传至云端，也不改变模型能力；它是对匹配识别原文的确定性替换。共用词典页面及手动测试说明见 [语音输入](voice-input.md)。


### 热词和语音别名的分工（2026-10-14）

[官方热词与上下文说明](https://docs.volcengine.com/docs/DoubaoVoice/hot-words-and-context?lang=zh)确认，当前使用的 `bigmodel_async` 二遍链路支持热词。可以在 `request.corpus.context` 中传 JSON 字符串，包含 `hotwords: [{word: "期望输出"}]`；也可以配置控制台热词表，再在 `request.corpus.boosting_table_id` 传表 ID。创建表本身不会让本应用自动使用它。直传与热词表可以合用，直传优先；流式一遍的热词容量较小，最终二遍能利用更多热词。

建议热词作为专有名词的主要入口，只选择难识别的词，而不是上传全部词典。现有语音别名相当于本机精确纠错规则，命中识别原文后替换为固定输出，作为可选兜底；Apple 本地模式也能使用。热词只是概率引导，格式原样输出仍由本机词典保护。VoiceInputVersion=8 时尚未发送热词或表 ID。用户已选定每次请求携带，VoiceInputVersion=9 按下述勾选方式接入；没有创建或修改云控制台词表。


### 每次请求携带勾选热词（VoiceInputVersion=9）

词典页面增加“豆包热词”复选框。旧词条和新增词条默认不勾选；勾选后点击“保存并部署”，下一次豆包录音生效。只有选中词条的“固定输出”发送，编码、权重、识别别名、不勾选词条以及文档上下文都不发送。重复输出词在本机去重，顺序与词典一致。勾选状态保存在本机 `mixed_user_dictionary.json`，也可按条取消；Apple 模式不发送热词。

发送方式：读取勾选词的录音快照，经本机助手管道传入，在 WSS 连接首个 JSON 配置帧写入 `request.corpus.context`。该字段是 JSON 字符串，内容只包含 `hotwords: [{word: "固定输出"}]`。每次录音连接发送一次，后续 PCM 音频分包不会重复发送。没有同步到控制台，也不需要额外控制台管理凭证。热词对一遍/二遍的容量和作用限制见[官方说明](https://docs.volcengine.com/docs/DoubaoVoice/hot-words-and-context?lang=zh)。

页面限制最多 5000 个不同热词；超大请求在本机拒绝。二遍可以利用更多热词，流式一遍可能按服务的较小 token 容量截断，所以精简勾选仍有意义。未勾选时首帧不含 `corpus`。

离线验证旧词典默认不上传、勾选存取和取消、输出格式原样保存；协议验证 JSON 字符串正确转义、去重、无其他词典字段。原生 WebSocket 连接通过本机模拟服务检查首帧只发送公开测试词“AI助手”“Mac 电脑”，后续音频包不重复发送。未用真实词典向云端做自动验收，热词识别效果由用户选择词条后手动测试。


凭证窗口支持 Command + V 粘贴、Command + A 全选和标准编辑命令。输入法后台应用没有常规编辑菜单，VoiceEditingWindow 会把这些快捷键转发给 AppKit 原生字段编辑器；API Key／Access Token 仍采用 NSSecureTextField，不预读剪贴板、不显示明文、不把密钥写入日志。打开配置后自动聚焦当前启用的凭证输入框。

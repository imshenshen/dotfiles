# 语音输入：Apple 本地与豆包二遍

本仓库的鼠须管构建加入流式听写。默认使用 Apple 本地识别，也可以在设置里选择[豆包云识别（二遍）](doubao-speech.md)。Apple `SpeechAnalyzer` / `SpeechTranscriber` 在本机识别简体中文，暂定结果持续显示在编辑器里，确认后的文字正式上屏。五笔、拼音与语音共用自定义词典和中英文间距设置；云候选保留。智能文字整理目前只有接口，没有启用服务。

## 使用

选择鼠须管，在可编辑的文本框中结束当前候选输入。设置页可以录入修饰键或组合快捷键；新配置默认 Option，本机保留用户已保存的 Control + Shift + D。默认操作如下：

| 操作 | 快捷键 |
| --- | --- |
| 开始 / 停止听写 | 默认轻按松开 `Option` 开始，或按住约 0.25 秒开始；再按一次结束 |
| 输入法内备用开始 / 停止 | `Control + Shift + Space` |
| 取消听写并撤销仍未修改的语音 | `Escape` |

输入法菜单提供“语音设置…”和开始 / 停止入口。听写时屏幕下方显示黑色胶囊浮条，左侧取消、中间实时波形、右侧完成；浮条不抢编辑器焦点。停止时会等待最后的识别结果；超过 12 秒则保留当前显示的文字并结束。本版暂不提供语音撤回：没有撤回菜单、快捷键或完成后的撤回按钮。取消录音仍会安全回滚本轮未手动修改的文字；应用自身的普通撤销由应用处理。

首次按快捷键先请求麦克风权限，不开始录音。允许后回到文本框，再按一次开始听写；这样系统权限弹窗不会打断编辑器的输入上下文。拒绝后可到系统设置 → 隐私与安全性 → 麦克风，允许鼠须管。使用系统当前选择的音频输入设备。停止后录音进程退出，不在后台继续录音。正式包采用 Developer ID 签名；首次从旧临时签名迁移可能需要重新授权，详见[签名与公证](signing.md)。

Apple 模式需要 macOS 26 或更新版本、支持 `SpeechTranscriber` 的设备及已安装的 `zh_CN` 语音模型。本机 Apple Silicon 已安装该模型。没有模型或设备不支持时会提示并停止，不会自动下载模型或切换云识别。安装包有 Apple Silicon 和 Intel 双架构，但这不代表每台 Intel Mac 都能运行新语音引擎。旧系统仍可使用五笔、拼音和云候选。

## 系统权限

- 麦克风：用于本地录音和声音测试。
- 输入监控：用于全局快捷键；不保存键盘输入内容。
- 辅助功能：用于结束时检查当前焦点、读取必要的短范围并安全写入。

设置页的“打开系统设置”会直接打开对应的系统权限页面。需要在 macOS「系统设置 → 隐私与安全性」中为鼠须管开启对应权限；必要时重新启动输入法或退出登录再登录。显式使用临时签名的开发包，每次代码变化都可能导致系统重新要求授权；正式包应保持同一签名身份。若系统开关已打开但设置仍显示未授权，先确认添加的是 `/Library/Input Methods/Squirrel.app`，移除旧条目再重新添加。仍不生效时，可在终端使用官方工具清除这两个应用专属记录，再由用户在系统设置重新允许：

```sh
tccutil reset Accessibility im.rime.inputmethod.Squirrel
tccutil reset ListenEvent im.rime.inputmethod.Squirrel
```

这会撤销鼠须管的旧授权，不会授予权限，也不影响其他应用。未授予全局权限时，输入法内备用组合键仍可用于测试。

## 选择输入设备

从鼠须管菜单的“语音设置…”打开配置窗口；也可以点击设置页“开始听写”，它会返回原应用再开始。

- **麦克风**：选择“跟随系统默认”或固定设备。固定设备只作用于鼠须管，不更改 macOS 或其他应用的默认设备。
- **测试麦克风**：开始仅测试输入音量，不识别、不上屏。说话时观察波形和“已收到声音”提示；无变化时检查所选麦克风、系统输入设置和声卡增益。再次点击停止，关闭、最小化或离开设置窗口也会停止测试。
- **刷新**：连接新设备后刷新列表。指定的设备断开时提示不可用，不自动改用其他设备；听写过程中设备配置变化会停止录音。

识别方式、模型与设备设置自动保存，下一次听写生效。设备使用稳定 UID 保存；另一台电脑需要重新选择自己的设备。设备设置保存在用户偏好 `im.rime.inputmethod.Squirrel.Voice` 中，与 Rime YAML 和用户词库独立。若设置窗口内先授权麦克风，授权后再点击“测试麦克风”。

波形来自所选输入通道的实际音量，界面平滑更新；不会在无声音时模拟说话动画。低音量会提示“麦克风暂无声音”。麦克风用途说明属于本机设置，不需要云服务。界面只选择设备，不要求用户选择声卡通道。

## 手动编辑保护

只有当前语音尾部允许识别器修订。写入前，模块核对宿主、光标、标记范围及该范围的文字，按 UTF-16 计算范围，不读取整份文档。

听写期间打字或使用方向键时，将仍然完整的暂定文字确认，停止接收当前段落的后续修订；收到该段落的最终事件后，下一段可在新位置继续。五笔或拼音候选尚未结束时，不把语音写到候选区里。编辑器自行改变文字或光标，也会触发保护。

开始时在原输入框边说边显示。切换应用或输入上下文后，录音继续，尚未写入的文字改在浮窗预览，文字在同一黑色浮条上方向上展开，完整内容保留到结束；不会自动恢复对旧输入框的写入。结束时检查当前焦点，只写入尚未交付的文字，避免重复已有段落。当前焦点不可编辑或不能可靠进行范围替换时，同一浮条保留可编辑文字，右侧按钮切换为复制，由用户点击才写入剪贴板；左侧 × 关闭结果。不会另开听写结果窗口。鼠标编辑及键盘编辑都先保护已有文字；后续识别不得覆盖已改动的范围。

实时上屏需要编辑器可靠提供 InputMethodKit 的光标、暂定文字和范围读取 / 替换能力。文本编辑的远端接口会将整段暂定文字报告为选区，模块同时校验标记范围及文字内容来兼容这一行为；最终段落要求可靠的光标和范围。辅助功能只在结束时对当前可编辑焦点进行范围写入，不读取整份文档。各类网页、终端和特殊编辑器需分别实测，不能从 AppKit 测试推断全部兼容。

## 隐私和预留接口

录音与麦克风预览在 helper 进程内存中处理；Apple 模式不上传，豆包模式通过固定 WSS 接口发送录音。识别事件通过父子进程管道交给鼠须管；没有本地 HTTP 端口、录音文件或转写日志。系统诊断仅记录启动 / 停止状态、音频格式与音量，不包含听写文字或音频样本。选择豆包后，仅把本次音频发送到火山引擎语音接口，凭证通过父子进程管道传递；不会把音频或听写文字交给现有拼音云候选。拼音云候选仍仅处理用户键入的拼音。

`rime/native/voice/VoiceEditing.swift` 定义 `VoiceTextOrganizer` 和 `VoiceOrganizeRequest`，包含文本、会话和修订号。当前没有实现或调用文字整理。以后接入时还需实现异步结果与宿主范围、版本的校验；不能直接把迟到的整理结果覆盖到已编辑文字上。

## 编译、安装和其他电脑

在仓库根目录执行：

```sh
bash rime/tools/build_squirrel.sh
bash rime/tools/install_squirrel.sh
```

编译需要 Xcode 26 或更新版本。构建脚本应用 `voice-input.patch`，编译语音桥接库和 `RimeVoice.app`，一并复制到鼠须管、签名和打包。无需付费 Apple 开发者账号或 API Key。安装过程备份旧应用与 Rime 数据，验证安装后的主程序、云插件、语音库和录音助手与构建产物相同。

另一台电脑可以直接安装 `rime/.build/squirrel/package/Squirrel.pkg`，不用重新编译，也不用安装 Xcode。麦克风、输入监控、辅助功能授权与语言模型是每台电脑独立的。安装包不包含个人词库；同步配置仍按[编译安装文档](build-squirrel.md)处理。原生语音代码改变时需要在一台电脑重新编译并分发新安装包；只改 YAML / Lua 时重新部署即可。

### 手动输入后后续语音顺序修复（10:04:16 构建）

## 共用词典、空格与左右快捷键（VoiceInputVersion=6）

在“语音设置…”里可以打开“用户词典…”，无需单独编辑 YAML。页面读取 `~/Library/Rime/custom_phrase.txt` 中的现有自定义词条；双击单元格编辑，支持添加、删除与“保存并部署”。保存前备份原词典，保留原文件的符号链接；发现外部修改时拒绝覆盖。该页面管理固定自定义词条，不编辑 Rime 自动学习数据库。

| 字段 | 用途 |
| --- | --- |
| 固定输出 | 严格保留大小写、空格与标点，例如 `AI助手` 或 `Mac 电脑` |
| 输入编码 | 五笔/拼音输入时召回该词条，例如 `aizs`；可为空，表示仅语音使用 |
| 权重 | 同编码词条的排序权重，可留空 |
| 语音识别别名 | 将识别得到的这段原文换成固定输出，例如“人工智能助手” → `AI助手`；不是联网热词训练 |

语音别名保存在 `~/Library/Rime/mixed_user_dictionary.json`，与编码词条共同构成自定义词典。语音在开始录音时读取快照，词典修改在下次录音生效；五笔、拼音点击“保存并部署”后生效。现有候选的自定义词条优先级保留。复制到其他电脑时同时复制这两个文件。

“中文与英文、数字之间自动加空格”默认开启：`今天用Mac写了3个文件` → `今天用 Mac 写了 3 个文件`。关闭后普通中英文交界的空格移除；英文词之间的空格和换行保留。命中的固定词条内部不调整，例如词典的 `AI助手` 不变成 `AI 助手`，`Mac 电脑` 也不会被压缩。规则应用于语音实时结果、跨应用预览与结束后的结果，以及鼠须管的五笔/拼音上屏；鼠须管英文直通输入在安全可读的输入框内也能补上交界空格。不会重写已存在的用户文档内容或用户手动输入的空格；其他输入法不受这个开关控制。

快捷键按钮可以录入单独的左/右 Option、Control、Shift、Command，也可录入原有组合键。轻按松开即启动；按住 250 毫秒也可启动，一次按下不会重复触发。录音中再按一次完成。按 Option 参与其他组合键或点击鼠标会取消尚未触发的启动手势。旧版只保存“Option”的配置仍兼容左右任意一侧；如要区分，点击快捷键按钮重新按下并松开所需那一侧。保持用户已有的 Control + Shift + D，不自动改成 Option。
